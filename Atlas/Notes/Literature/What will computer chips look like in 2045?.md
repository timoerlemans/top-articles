# What will computer chips look like in 2045?

Bron: Dwarkesh Patel · mailto:reader-forwarded-email/e1fbe740a1555539ec2b069241448a7f

## Highlights

> One thing that did also come out of 10 nanometer is we started to define a set of maturity metrics. We use those maturity metrics in a process which we call phase gate, where we would say, “To go from pathfinding into development, these are the criteria that we need to go hit.” There are yield criteria, defect criteria, performance criteria, and we need to hit those in order to move to the next set of the flow.

> Staying on schedule is hard partly because new transistor designs take decades to mature. Modern chip transistors evolved from the planar MOS transistor, demonstrated in 1960. The history of transistors since has been the progression from two dimensions into three. Each development that Chris goes on to describe, from FinFET to gate-all-around, is a step in that progression. So it’ll help to first look at a basic transistor and how its parts have changed over time.
