# Nobody Has A Photographic Memory

Bron: Tommy Blanchard · mailto:reader-forwarded-email/a611eb39051e4c28001498b4bc765de4

## Highlights

> In the scientific literature, “eidetic memory” means something quite different. People with an eidetic memory report a vivid lingering image of a visual scene after that scene is taken away. Eidetikers (as they’re sometimes called) are almost always children, with the ability becoming less common with age.
